# PAUL_HIGHSCHOOL

St. Paul's High School (Belgaum) — Homepage Redesign Mockups & Assets

## Overview
This repository contains self-contained homepage design concepts created for St. Paul's High School (Belgaum). All images, styling (via CDN), and interactive elements are bundled locally for standalone viewing and client presentations.

## Contents
- **`index.html`**: Interactive Client Review Hub with responsive preview switcher (Desktop, Tablet, Mobile) and live iframe renderer.
- **`mockup1.html`**: Concept 1 — *Prestige Heritage & Classic Grid* (Jesuit heritage aesthetic, dynamic hero slider, stats showcase, and alumni highlights).
- **`mockup3.html`**: Concept 3 — *Editorial Academic Broadsheet* (Prestigious editorial broadsheet typography, academic notices, and rich gallery).
- **`images/`**: Complete set of 25 localized image assets used across the mockups (logos, historical photos, campus architecture, and event photography).

## How to Run Locally
Simply open `index.html` or any mockup directly in any modern web browser, or serve via any static HTTP server:

```bash
# Using Python
python3 -m http.server 8080

# Using Node.js
npx serve .
```
